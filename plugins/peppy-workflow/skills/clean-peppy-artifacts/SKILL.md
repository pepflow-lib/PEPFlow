# Clean Peppy Artifacts

Read the [canonical optional skill](../../optional/clean-peppy-artifacts/SKILL.md) and its linked distribution workflow.

Preserve existing workflow and publication deliverables independently of main-notebook Run All inputs: main setup modules, all completed B1-B5 states, required dense/relaxed/certificate/basis/rank/dual/closed-form data, and their transitive dependencies. Keep existing `state/` and `supplementary/` roots with meaningful content even when the notebook inlines or regenerates their files. Trace workflow consumers, supported notebook paths, and publication/run instructions. Read an available manuscript; do not claim a paper audit without it. Retain uncertain roles and explicitly requested additional deliverables.

Apply the canonical skill's narrow source-authentication and delivery-reference exceptions; preserve numerical/proof certificate data, mathematical checks, and the five-block workflow. Keep IDs unchanged unless a verified metadata-only delivery-path migration requires recomputation and propagation under the canonical workflow. Preserve cell count, order, IDs, types, execution numbers, formulas, saved outputs, metadata, and paper references, and verify the numbers during fresh-kernel replay. Remove only demonstrably disposable debris outside protected artifact roles and authentication-only source machinery; historical source metadata may remain inert in protected certificates.

An original evaluation archive is a source for a distinct delivery destination, not an in-place deletion target. A selected completed example or delivery directory can be cleaned in place. Resolve ambiguous scope, retain uncertain dependencies, and honor review-only requests.

Validate required evidence/basis/rank/certificate references and supported helper paths, separately from historical rejected-trial logs. Missing required evidence requires recovery or validation from sufficient saved data; do not delete the reference, substitute placeholders, or claim the handoff complete. Preserve saved outputs except corresponding path/ID strings in a verified migration. Validate the protected artifact inventory and retained dependencies, then replay in a disposable tree with a fresh kernel and the intended environment, isolating source paths and writes. Report unperformed checks honestly. Successful notebook execution alone does not validate the workflow/publication delivery. Use the response or requested PR description to report source edits, protected artifacts, removals, exceptions, and actual verification; create no cleanup reports, restoration infrastructure, or backup trees by default.

Invoking cleanup authorizes the canonical skill's scoped source-authentication/reference edits and verified removal of disposable debris without a second general inventory approval. It does not authorize dropping protected workflow or publication deliverables. Creating, updating, or reviewing the skill does not invoke cleanup. Existing invocation policy is unchanged.
